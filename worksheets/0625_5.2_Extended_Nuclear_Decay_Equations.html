Section A: balancing decay equations

Each equation shows the decay of a nucleus. Complete each equation by writing the missing numbers or the missing symbol on the dotted lines. Write each completed equation on paper, then check it.

1

Uranium-238 decays by α-emission.

23892U → ....................Th + 42α

Mark scheme

Working Nucleon number: 238 – 4 = 234. Proton number: 92 – 2 = 90.

Carbon-14 decays by β-emission.

146C → ....................N + 0–1β

[1]

Mark scheme

146C → 147N + 0–1β

Working Nucleon number is unchanged: 14. Proton number: 6 = Z + (–1), so Z = 7.

Strontium-90 decays by β-emission.

9038Sr → 90..........Y + ....................β

[1]

Mark scheme

9038Sr → 9039Y + 0–1β

Working The β-particle is written with nucleon number 0 and proton number –1. Then 38 = Z – 1, so Z = 39.

[1]

Mark scheme

Working Work backwards: 131 + 0 = 131 and 54 + (–1) = 53.

7

Cobalt-60 emits a β-particle and γ-radiation.

6027Co → ....................Ni + 0–1β + γ

[1]

Mark scheme

6027Co → 6028Ni + 0–1β + γ

Working The γ-radiation changes neither number. The β-emission leaves 60 unchanged and raises the proton number to 28.

8

A nucleus of technetium-99 emits γ-radiation only.

9943Tc → ....................Tc + γ

[1]

Mark scheme

9943Tc → 9943Tc + γ

Working γ-emission changes neither the proton number nor the nucleon number. The nucleus only loses energy.

9

Polonium-210 decays to lead-206. Write the symbol for the emitted particle in nuclide notation.

21084Po → 20682Pb + ..............................

[1]

Mark scheme

21084Po → 20682Pb + 42α

Working The nucleon number falls by 4 and the proton number by 2, so the particle is an α-particle.

10

Polonium-218 decays by α-emission to an isotope of lead. This isotope of lead then decays by β-emission to an isotope of bismuth.

21884Po → ....................Pb + 42α ....................Pb → ....................Bi + 0–1β

[2]

Mark scheme

21884Po → 21482Pb + 42α 21482Pb → 21483Bi + 0–1β

Working First decay: 218 – 4 = 214 and 84 – 2 = 82 (1 mark). Second decay: 214 unchanged and 82 + 1 = 83 (1 mark). The product of the first decay is the starting nucleus of the second.

Section A: connection and common mistakes

Connection In every equation the total nucleon number (top numbers) is the same on both sides, and so is the total proton number (bottom numbers). Check both sums after completing each equation.

Common mistakes Three errors account for most lost marks in decay equations. (1) Writing the β-particle with proton number +1 or 0 instead of –1. (2) Subtracting 4 from the proton number and 2 from the nucleon number in α-decay, which is the wrong way round. (3) Changing the nucleon number in β-decay: a neutron becomes a proton, so the total number of nucleons stays the same.

Section B: multiple choice

One mark each. Select an answer to check it.

1

A nucleus of thorium, Th, emits an α-particle and changes into a nucleus of radium, Ra. The equation shows the change.

23290Th → abRa + 42α

What are the values of a and b?

ab
A22886
B22888
C23688
D23692
Mark scheme

Answer B

Explanation Nucleon number: 232 = a + 4, so a = 228. Proton number: 90 = b + 2, so b = 88.

Connection Balance the top row and the bottom row separately.

Common mistake Choosing A by subtracting 4 from both numbers, or D by adding instead of subtracting.

2

A nucleus decays by emitting a β-particle.

Which row shows what happens to the proton number and to the nucleon number of the nucleus?

proton numbernucleon number
Adecreases by 1does not change
Bincreases by 1does not change
Cincreases by 1decreases by 1
Ddoes not changedoes not change
Mark scheme

Answer B

Explanation In β-emission a neutron in the nucleus changes into a proton and an electron. There is one more proton and one fewer neutron, so the proton number increases by 1 and the nucleon number does not change.

Connection The syllabus states this change as neutron → proton + electron.

Common mistake Choosing A because a negative particle is emitted. Losing a charge of –1 makes the nucleus more positive, so the proton number goes up.

3

The grid shows nucleon number plotted against proton number. Each small square represents one unit. The position of a nucleus X is marked.

Which arrow shows the change when nucleus X emits a β-particle?

Mark scheme

Answer C

Explanation β-emission increases the proton number by 1 and leaves the nucleon number unchanged, so the arrow points one square to the right. Arrow A, two squares left and four squares down, is α-emission.

Connection A decay chain can be drawn on this kind of grid as a sequence of these two arrows.

Common mistake Choosing B, which lowers the proton number by 1.

4

A nucleus emits one α-particle and then two β-particles.

How does the final nucleus compare with the original nucleus?

Mark scheme

Answer D

Explanation The α-emission lowers the proton number by 2 and the nucleon number by 4. Each β-emission raises the proton number by 1. Overall the proton number changes by –2 + 1 + 1 = 0 and the nucleon number by –4.

Connection The same proton number with a different nucleon number means the final nucleus is another isotope of the original element.

Common mistake Choosing A by ignoring the two β-emissions.

5

A nucleus of lead, 21482Pb, decays by emitting a β-particle.

How many neutrons are in the nucleus that is produced?

Mark scheme

Answer A

Explanation After β-emission the nucleon number is still 214 and the proton number is 83. Number of neutrons = 214 – 83 = 131.

Connection Number of neutrons = nucleon number – proton number, applied to the product, not to the original nucleus.

Common mistake Choosing B, the number of neutrons in the original nucleus (214 – 82).
